как копировать

В Telegram — кладёт в буфер готовое форматирование: жирный, курсив и пустые строки между абзацами. Вставляете прямо в поле ввода канала. Если браузер форматирование не пропустил, в поле окажется разметка **жирный** / __курсив__ — Telegram превратит её в оформление при отправке, звёздочки схлопнутся сами.

В MAX — чистый текст без звёздочек. MAX не принимает ни вставленное оформление, ни markdown (проверено 08.10.2026): жирный ставится руками через меню «Форматирование», а с оформлением публикуем через API (бот или Postmypost).

HTML для Salebot — тот же текст, но разметка тегами <b> и <i>, ссылка голым адресом. Вставляете в блок сообщения Salebot.

Править можно прямо здесь: кликните в текст поста. ⌘B жирный, ⌘I курсив, Enter новый абзац. Правки сохраняются в этом браузере, кнопки копируют уже исправленный текст. Кнопка «Правки для Claude» кладёт в буфер все изменённые посты, чтобы прислать их в чат.
